# ChinaGoods | Предзаказ 2027 — ВК-бот с GigaChat

Чат-бот сообщества ВКонтакте: отвечает подписчикам на сообщения через
API GigaChat (Сбер) в роли консультанта Алексея, используя базу знаний
о товарах из Китая, предзаказе, доставке и оплате.

## Возможности

- Приём сообщений сообщества через Bots Long Poll (`VkBotLongPoll`)
- Ответ на каждое входящее сообщение через GigaChat (SDK `gigachat`)
- Системный промпт для консультанта + содержимое `knowledge_base.md`
- Вежливая заглушка при сбое GigaChat
- Чтение всех ключей из `.env` (secret'ы в коде не хардкодятся)

## Требования

- Windows / Linux / macOS
- Python 3.10+
- Аккаунт GigaChat API (физлицо или B2B) с доступом к модели
- Сообщество ВКонтакте с включённым Bots Long Poll и правом на сообщения

## Переменные `.env`

Скопируйте `.env.example` в `.env` и заполните значения:

| Переменная | Описание |
|---|---|
| `GIGACHAT_CREDENTIALS` | `base64(Client_ID:Client_Secret)` от GigaChat API |
| `GIGACHAT_SCOPE` | Область доступа, для физлиц — `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | Модель, например `GigaChat-2-Max` |
| `GIGACHAT_VERIFY_SSL_CERTS` | `true`/`false` — проверка TLS-сертификата (на Windows без сертификата НУЦ Минцифры — `false`) |
| `VK_TOKEN` | Ключ доступа сообщества ВКонтакте |
| `VK_GROUP_ID` | ID сообщества, только цифры, без минуса |

`.env` содержит реальные секреты и не должен попадать в git (он уже в
`.gitignore`).

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python bot.py
```

Бот подключается к сообществу и начинает отвечать на входящие сообщения.
Остановка — `Ctrl+C`.

## Структура проекта

```
bot.py                  — основной код: GigaChat + VK LongPoll
knowledge_base.md       — база знаний (добавляется в системный промпт)
requirements.txt        — зависимости Python
.env.example            — шаблон переменных окружения
.env                    — реальные секреты (не коммитить!)
Документы_GigaChat_API/ — учебные материалы по GigaChat API
AGENTS.md               — инструкция для агентов
```

## Настройка сообщества ВКонтакте

1. Управление сообществом → Работа с API → Long Poll API → включите Long Poll
   и «Разрешить Bots Long Poll».
2. Создайте ключ доступа с правом на сообщения (`messages`).
3. Убедитесь, что у сообщества включены «Сообщения» (Разделы → Сообщения).
