# AGENTS.md

Учебный проект (урок курса): ВК-бот сообщества **ChinaGoods | Предзаказ 2027**.

## Назначение проекта

- ВК-бот консультирует клиентов по товарам из Китая, предзаказу, доставке и оплате.
- Ответы формируются через GigaChat API с системным промптом «Алексей» и подключённой базой знаний.
- Запуск: `python bot.py` (точка входа `run_vk_bot`).

## Стек технологий

- Python 3.12+
- `vk_api` — VkBotLongPoll (Bots Long Poll API)
- `gigachat` — официальный SDK Сбера
- `python-dotenv` — загрузка переменных из `.env`
- `requests` — обработка сетевых ошибок LongPoll
- `time` — паузы при переподключении

## Структура проекта

- `bot.py` — точка входа, вся логика бота
- `knowledge_base.md` — база знаний (подключается в системный промпт)
- `.env` — секреты (НЕ коммитить, в `.gitignore`)
- `.env.example` — шаблон переменных без значений
- `.gitignore` — защита `.env`, игнор venv/`__pycache__`
- `README.md` — инструкция для людей
- `requirements.txt` — зависимости
- `Документы_GigaChat_API/` — официальная документация GigaChat (.docx, на русском; в именах файлов кириллица и пробелы — всегда в кавычках)

## Переменные окружения (только названия)

- `GIGACHAT_CREDENTIALS` — значение: base64(`Client_ID:Client_Secret`), без сырых ключей
- `GIGACHAT_SCOPE=GIGACHAT_API_PERS` — скоуп для физических лиц (у бизнес-аккаунтов иной)
- `GIGACHAT_MODEL=GigaChat-2-Max` (старые названия моделей могут быть устаревшими)
- `GIGACHAT_VERIFY_SSL_CERTS` — временно `false` для теста (на Windows без сертификата НУЦ Минцифры SDK падает с проверкой TLS)
- `VK_TOKEN`
- `VK_GROUP_ID` — только цифры, без ведущего минуса id группы

## Ключевые технические решения

- LongPoll через `VkBotLongPoll` (`from vk_api.bot_longpoll`), события — `MESSAGE_NEW`.
- Поля события (`from_id`, `text`, `peer_id`) читаются из `event.obj['message']`, а не с верхнего уровня `event.obj`.
- `random_id` генерируется вручную через `random.randint`.
- Устойчивость к сетевым ошибкам: при `ReadTimeout`/`ConnectionError` бот печатает `[VK] Потеряна связь с LongPoll...` и переподключается через 3 секунды (объект `VkBotLongPoll` пересоздаётся).
- При других исключениях — печать сообщения об ошибке и переподключение через 3 секунды.
- При Ctrl+C — корректный выход с сообщением «Бот остановлен пользователем.»
- Системный промпт + база знаний объединяются в одно system-сообщение GigaChat.
- Бот общается с пользователем только на «вы», никогда на «ты».

## Правила безопасности

- Реальные ключи — только в `.env`.
- `.env` в `.gitignore`.
- В коде нет хардкод-ключей — всё через `os.getenv`.
- Никогда не выводить секреты в консоль, чат, скриншоты.

## Роль бота

- Имя: Алексей.
- Говорит в мужском роде.
- Общается только на «вы», никогда на «ты».
- Вежливый, но не навязчивый (без агрессивных продаж).
- Отвечает только по теме товаров и предзаказа; вне темы — мягко возвращает к ассортименту; при незнании — предлагает менеджера.
- Не выдумывает информацию, которой нет в базе знаний.
- В конце диалога предлагает оставить заявку на предзаказ.
